Build the Android app and run it on a local emulator using mobile-mcp.

Default emulator: The first available Android emulator found via mobile-mcp (typically emulator-5554)

Steps:
1. Build the debug APK
2. List available devices using mobile-mcp
3. Install the APK on the first available emulator
4. Launch the app (com.example.helloworld/.MainActivity)
5. Confirm the app is running successfully
