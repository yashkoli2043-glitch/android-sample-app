Discard all local changes and reset to the latest commit on origin.

Steps:
1. Check git status to see what changes will be discarded
2. Fetch the latest changes from origin
3. Show what commits will be lost (if any)
4. Reset hard to origin/main (or current branch's upstream)
5. Clean untracked files and directories
6. Verify the working directory is clean

IMPORTANT: This command will permanently delete all local changes. Always confirm with the user before proceeding.
