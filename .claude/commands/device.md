Build the Android app and run it on a real device via BrowserStack using browserstack-mcp.

Default device: Samsung Galaxy S24 running Android 14.0

Steps:
1. Build the debug APK
2. Launch a BrowserStack App Live session on Samsung Galaxy S24 (Android 14.0)
3. Upload and install the APK automatically
4. Provide the BrowserStack session URL for manual interaction
5. Confirm the session was launched successfully
