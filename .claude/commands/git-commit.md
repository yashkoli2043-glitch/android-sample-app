Commit all local changes (including untracked files) and push to origin.

Steps:
1. Check git status to see all changes
2. Show git diff for modified files
3. Review recent commit messages to follow the repository's commit style
4. Stage all changes including untracked files (git add -A)
5. Create a descriptive commit message that summarizes the changes
6. Commit with the standard footer (Claude Code attribution)
7. Push to origin
8. Confirm the push was successful
